# Context: Components

## Overview
The application houses UI components in the `components/` directory, following a clean, modular structure. The base components are designed for reusability.

## Base Directory (`components/`)
- `Logo.tsx`: Renders the main ToyotaTech/application logo (likely an SVG or Image component).

## UI Library (`components/ui/`)
Contains common, reusable UI primitives heavily utilized across the app.
- `Button.tsx`: A flexible button component supporting different variants (primary, secondary, outline, etc.), states (disabled, loading), and icons.
- `TextInput.tsx`: A custom text input field, likely supporting labels, error states, and secure text entry formatting.
- `SocialButton.tsx`: Specific button variants for social login providers (e.g., Google, Apple).
- `ScreenSectionHeader.tsx`: A standardized header for screen sections, maintaining consistent typography and spacing.
