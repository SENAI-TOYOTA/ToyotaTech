# Arquivo — Documentação do Monolito Descontinuado

Documentos históricos do monolito em C#/.NET 8 (ASP.NET Core Web API) e das aplicações Web/Mobile do semestre anterior. Estes materiais foram descontinuados com a remoção de `apps/api` em 26/08/2026 (commit `af564a3`) e são mantidos apenas para consulta acadêmica.

O sistema atual é composto por **aplicativo mobile** (Expo/React Native) e **backend serverless na AWS**. A documentação vigente está na [Wiki do projeto](https://github.com/SENAI-TOYOTA/ToyotaTech/wiki/Backend-Serverless).
